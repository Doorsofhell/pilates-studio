# Pilates Studio

Application PWA mobile-first de Pilates au sol et Pilates Reformer.

## Version 0.1
Six séances guidées avec chronomètre, filtres, profil local, historique et statistiques. Les programmes 7/14/30 jours sont des entrées de découverte et non encore des calendriers individualisés. Pas de vidéos ni coach 3D dans cette version.

## GitHub Pages
Settings > Pages > Build and deployment > Source : GitHub Actions. Puis lancer le workflow Deploy GitHub Pages si nécessaire.

URL cible : https://doorsofhell.github.io/pilates-studio/

## Sécurité
Pour le Reformer, vérifier les réglages constructeur et pratiquer sous supervision qualifiée si débutant. Arrêter en cas de douleur.
